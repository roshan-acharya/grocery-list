# 🛒 Grocery List App

A **simple CRUD web application** to manage grocery items, built with **HTML, CSS, and JavaScript**. The app uses **localStorage** to save items.

---

## 🌐 Demo

Try it live: [Grocery List App Demo](https://roshan-acharya.github.io/grocery-list/)

---

## ✨ Features

- **Add Items** – Quickly add groceries to your list.
- **Edit Items** – Update the name of an existing item inline.
- **Delete Items** – Remove items from your list.
- **Mark Completed** – Check items as done with a **line-through effect**.
- **Persistent Storage** – Items are saved in `localStorage` automatically.
- **Responsive Design** – Works on mobile, tablet, and desktop.

---

## 🛠 Technologies Used

HTML5 – App structure

CSS3 – Styling, responsive layout, black & white theme

JavaScript (ES6) – CRUD functionality, DOM manipulation, event handling, localStorage
